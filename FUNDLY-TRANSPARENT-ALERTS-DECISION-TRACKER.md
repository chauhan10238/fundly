# Fundly Transparent Alerts & Decision Tracker

## Added

- Every Investor Hub alert now shows its source and confidence.
- Portfolio Health Score with clear strengths and weaknesses.
- Recommendation Performance card with measured success rate, average gain and average loss.
- Recommendation History renamed in-page to Investment Decision Tracker.
- Recommendations now save their source names and confidence contributors.
- Users can mark recommendations Pending, Executed, Partially Executed or Ignored.
- Users can save action notes explaining why a recommendation was followed or ignored.

## Alert source meanings

- **Fundly Portfolio Risk Engine**: concentration calculations from the current profile's holdings and settings.
- **Fundly Portfolio & Cost Basis**: drawdown calculations from current prices and recorded average costs.
- **Fundly Decision Journal**: governance checks based on saved theses and review information.

No new paid API is required for these features. FMP and the existing analysis sources are captured when a recommendation is logged.
